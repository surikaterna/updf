# Declarative TypeScript roadmap

These issues describe proposed follow-up work for the experimental declarative TypeScript proof. The proof itself is local-only at `experimental/declarative/` on the `feature/declarative-cmr-poc` worktree based on `7782bb3`; it is not a published package or released UPDF capability. Issue creation does not mean implementation is underway or complete.

This list excludes the active painting/SVG work (focus 2). The raster-image issue is a separately tracked follow-up that depends on shared painting/resource semantics; it is not part of the painting/SVG issue. No issue was created for that active focus here.

JPEG image controls

Four placements share one baseline JPEG resource. Width changes PDF geometry, not the 32×24 source pixels. The example calculates aspect ratio explicitly; the engine does not auto-fit.

Progressive JPEG, EXIF and ICC profiles are not supported. Select PNG for transparency. These original MIT samples use the supported baseline profile; there is no file upload.

PNG image controls

Four placements share one image and soft mask. Opaque, half-transparent and clear quadrants appear over white and blue. Width changes PDF geometry, not the 32×24 source pixels.

Non-interlaced 8-bit PNG only. ICC/gamma/chromaticity metadata, APNG and other bit depths are unsupported. Original MIT samples; no file upload. Clipping is not redaction.

PNG preparation uses native compression streams (Chrome/Edge 80+, Firefox 113+, Safari 16.4+); no compression library is downloaded.

Code 39 controls

1–80 basic Code 39 characters: uppercase A–Z, digits, space and -. $/+%. No automatic uppercase conversion or embedded *. Quiet zones are included. Symbols wider than 432 points reject; modules are never squeezed.

QR controls

Printable ASCII only. Versions 1–10 with four quiet modules on every side. H may need more space; over-capacity payloads reject without lowering correction. URLs are encoded as data, never requested. No logo overlays or hardware-scanner guarantee.

Font URI controls

Changing engines re-prepares the active font from the same bytes, not the URI draft. Only the selected engine is imported; engines already used stay in the browser cache. No automatic fallback: a failed switch keeps the previous font and PDF active.

Press Generate PDF to request the entered URI. Typing does not fetch. The initial preview and Reset use bundled Liberation Sans; title/size edits reuse the last successful font, even while editing a URI or after a failed replacement.

Use a direct static .ttf file, up to 4 MiB. Google Fonts CSS URLs, WOFF/WOFF2 and variable fonts are not supported. Fontkite has a narrower format profile; choose Fontkit explicitly if a font is unsupported. Requests omit credentials and reject redirects; browser CORS applies.

Loading a submitted URL contacts that host. Use trusted fonts with embedding permission. The default URL is Google Fonts Roboto (Apache-2.0); no external font is requested until you press Generate PDF.

Arguments for this result

Source is shown verbatim, not rewritten with your inputs. Uppercase TSX names are imported components; lowercase names are native drawing intrinsics. Included helpers are labeled below. The chart is application-owned; SVG block/inline helpers are optional public exports from @updf/svg/layout, not core intrinsics.

Core first. Optional means optional.

The entry loads core, not React, font parsers, Node APIs or SVG. Native VDOM, measured TSX templates and layout demos load on demand, as do the SVG adapter and geometry. Native paths need no geometry adapter.

Fonts can use prepared resources through @updf/fonts. The font-URI demo lets you explicitly choose @updf/fontkit or experimental @updf/fontkite to prepare trusted static TrueType bytes. The initial entry stays parser-free; freight still uses Fontkit. The font demo uses the shared optional asset loader, not an image decoder.

  • Core uses fixed point geometry and explicit pages. Optional layout supports measured blocks, padding/border/gap and error/hidden overflow, repeated regions and explicit-width atomic table rows, not general CSS layout or row/column spans.
  • Built-in Helvetica: printable ASCII and LF. No shaping, bidi or full SVG. The optional @updf/jpeg showcase demonstrates baseline color/grayscale images with explicit sizing and reuse. The separate @updf/png showcase adds non-interlaced 8-bit PNG and alpha. Broader image profiles remain unsupported.
  • Prepared fonts support a documented simple LTR Latin/Cyrillic profile, not general typography.
  • Code 39 and QR demos load separately on demand and paint native vectors. QR uses the local encoder with M/H correction, not an external generator. Payloads are data, never network requests. Barcode profiles and fit are bounded; logos, PDF417 and automatic Flow placement are not included.
  • Runtime validation and current resource caps still apply. Trusted components are not a sandbox.

Experimental, unreleased native implementation. These mock documents are not operational paperwork.

Arguments for this result

Source is shown verbatim, not rewritten with your inputs. Uppercase TSX names are imported components; lowercase names are native drawing intrinsics. Included helpers are labeled below; chart and SVG adapters are application examples, not built-in Chart or Svg APIs.

Core first. Optional means optional.

The entry loads core, not React, Fontkit, Node APIs or SVG. Native VDOM, measured TSX templates and layout demos load on demand, as do the SVG adapter and geometry. Native paths need no geometry adapter.

Fonts can use prepared resources through @updf/fonts; the optional @updf/fontkit adapter prepares trusted static TrueType bytes. The initial entry remains parser-free; opting into the freight invoice loads Fontkit and two licensed Liberation Sans font assets (regular and bold).

  • Core uses fixed point geometry and explicit pages. Optional layout supports measured blocks, padding/border/gap and error/hidden overflow, repeated regions and explicit-width atomic table rows, not general CSS layout or row/column spans.
  • Built-in Helvetica: printable ASCII and LF. No shaping, bidi or full SVG. Optional @updf/jpeg supports bounded baseline JPEG resources in the engine; this showcase has no image demo. PNG/alpha and broader image profiles are not delivered.
  • Prepared fonts support a documented simple LTR Latin/Cyrillic profile, not general typography.
  • Runtime validation and current resource caps still apply. Trusted components are not a sandbox.

This previews the private, unreleased native implementation, not legacy 0.4.15. Merged features are not a package release; open roadmap acceptance is not delivered. Legacy remains separate; a fixed CMR reference is not operational freight paperwork.

Roadmap, not promises

Compared with GitHub issues on October 7, 2026, against merged develop revision 21dcd48. Native packages remain private and unreleased. This is a dated comparison, not a release or deployment record; linked issues carry current acceptance details. Ordering below is by issue number, not priority or a delivery commitment.

Open acceptance scope

  • #29 Bounded Markdown lists · structured input versus an optional constrained parser is undecided; markers, wrapping, nesting and pagination remain unimplemented. No CommonMark/GFM promise.
  • #30 Native Code 39 · legacy support is not native TypeScript support. Validation, sizing, quiet zones and independent decoding evidence remain open.
  • #31 QR codes · native generation is absent; a bounded encoding/error-correction profile, quiet-zone/fit rules and independent decoder tests are still needed.
  • #32 Bundle-cost and feature regression gates · graph checks and measurements exist; reviewed numeric thresholds and CI material-regression/baseline-approval policy remain incomplete. No size caps are promised here.
  • #35 README, examples and roadmap · earlier documentation merged, but final status reconciliation, review and authorized delivery remain open. This Pages comparison does not close the wider documentation acceptance.
  • #47 Optional SVG string/TSX authoring and adapters · XML compilation and the tree entry exist; typed SVG TSX and supported block/inline exports, sizing/baseline contracts and isolated consumer-graph proof remain open. App-owned adapters are examples, not supported exports.
  • #54 Positioned Blocks · relative/absolute/fixed positioning, containing-block and fragmentation rules, paint ordering and fit diagnostics remain unimplemented. Fixed image coordinates are not positioned Blocks.
  • #55 Auto-height regions with final pagination context · explicit-height final context works; auto-height convergence, cycle detection, cumulative iteration/work budgets and trial-resource ownership remain open.
  • #56 Kernel-backed Row/Column alignment · width resolution and placement foundations exist; positive residual-space distribution, consistent Column cross-axis alignment, legacy style migration and definite-height/fragmentation rules remain open. No full flexbox promise.

Merged implementation · closed issues, not a native release

  • #25 Configurable resource budgets · accepted trusted/service profiles and resource-byte accounting; does not deliver #55 cumulative trial-work guarantees.
  • #26 Rich text and measurement, #27 Flow and page templates, and #28 Paged tables · merged foundations, not open/unmerged local proofs.
  • #33 Raster images: bounded JPEG v1 only · merged via PR #66 with optional @updf/jpeg and shared resource/XObject support. PNG/alpha, progressive/CMYK/EXIF/ICC and decoders remain unsupported/future work; the broad image roadmap is not complete.
  • #34 Workspace restructuring · merged via PR #36; #35 documentation acceptance remains open.
  • #41 Public authoring APIs, #42 Per-edge borders, #43 Inline backgrounds, #44 Row/Column composition, #45 Flexible table widths, and #46 Invoice/manifest examples · merged bounded capabilities.
  • #49 Typed style conventions, #51 Fractional geometry, #52 PageBreak, and #53 Normal-flow auto margins · merged; not full CSS or completion of #54–#56.

#48 Intermittent Chromium black frames is closed / not planned: investigation is deferred, root cause remains unknown and no production fix is claimed. #50 SVG signature reference mismatch was fixed separately; it does not resolve #48.

For changes after this comparison, consult current open GitHub issues, not historical roadmap snapshots.

Demo availability is not a native package release or completion of open roadmap acceptance. See the dated issue comparison above for merged and remaining scope.
